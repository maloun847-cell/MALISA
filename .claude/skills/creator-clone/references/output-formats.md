# Output formats

Keep outputs scannable. Evidence references look like `V03 @04:10`. Use "extrapolating" when there's no direct evidence.

## Idea card

```markdown
### [Core | Stretch | Wildcard] — <working title in the creator's title style>
**Hook (their words):** "<first 1–2 lines exactly as they'd say them>"
**The idea in one line:** …
**Why he'd make this:** <engine it comes from + evidence, e.g. "same 'what if I actually tried it' engine as V02 and V05, his two best performers">
**Story shape:** <3–5 beats, one line each>
**What makes it his and not anyone's:** <the signature devices it relies on>
**Risk:** <what could make it flop or feel off-brand>
**Confidence:** <1–5> — <one-line reason>
```

After the cards, add one line: which idea you'd make first and why.

## Video structure

```markdown
# <working title> — structure
Target length: <mm:ss> (his typical: <x>) · Format: <talking head / vlog / …> · Based on: <beat sheet from profile, nearest videos>

## Promise
What the viewer is told they'll get, and the moment they're told (aim for his usual timing).

## Beats
| Time | Beat | What's said / happens | On screen | Purpose | Loop |
|---|---|---|---|---|---|
| 00:00–00:20 | Cold open | … | … | Hook: stakes | opens L1 |
| … | | | | | closes L1 |

## Retention risks
- <timestamp>: <why viewers might leave> → <how he'd patch it (cutaway, reveal tease, joke, pattern interrupt)>

## Alternative structure (if relevant)
One paragraph: the other way to tell it and when it would be better.
```

## Script (A/V format)

```markdown
# <title> — script v1
Word budget: <wpm> wpm × <minutes> = ~<n> words · Language: <…>

| # | SAID (voice) | SHOWN (visual / edit) |
|---|---|---|
| 1 | "…" [sig: cold-open-on-worst-moment] | Close-up, handheld… |
```

Rules: write it the way they talk, not the way they'd write an essay — contractions, their filler words in moderation, their sentence rhythm. Read it back in their voice; anything that sounds like a LinkedIn post gets rewritten.

## Packaging

```markdown
## Titles
Formula A — "<formula>" (used in V02, V05)
1. …  ← ship this one
2. …
Formula B — …

## Thumbnails
1. <subject + expression> · <text, if he uses text> · <colours> · <composition> — why it matches his pattern
2. …

## First 30 seconds (full)
…
```

## Gut check rubric

Score each 1–5, with one line of evidence each:

| Dimension | Question |
|---|---|
| Engine fit | Does it come from the same place his ideas come from? |
| Voice fit | Does it sound like him? |
| Structure fit | Does it move like his videos move? |
| Promise & payoff | Is the promise clear early and paid off the way he pays off? |
| Packaging fit | Would this title/thumbnail sit naturally on his channel page? |
| Freshness | Is it new, or a rerun of one of his existing videos? |
| Anti-patterns | Does it break anything he never does? (any hit = flag) |

Then: **Verdict** (Make it / Make it with changes / He wouldn't make this), **Keep**, **Cut**, **Change**, written as the creator talking to their own editor.
